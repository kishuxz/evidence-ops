# Evaluation corpus

The v0.1 corpus is **200 synthetic constructed single-author engineering
fixtures awaiting expert review**.

A reviewer package (`@evidenceops/review-pack`) exists so qualified external
reviewers can later adjudicate cases. Importing completed reviews does **not**
flip `independentReview` or `reviewStatus`. This repository has **not** performed
expert legal review.

It is **not**:

- expert-reviewed
- independently reviewed
- naturally occurring
- public-source CourtListener/RECAP data
- a live citator snapshot

The original eight cases remain the foundation slice. Privileged client material
is forbidden.

See `@evidenceops/eval`, ADR 0010, and ADR 0022.
